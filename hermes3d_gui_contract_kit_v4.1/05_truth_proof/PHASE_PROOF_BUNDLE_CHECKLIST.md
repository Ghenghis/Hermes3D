# Phase Proof Bundle Checklist

Each phase proof bundle must include manifest, branch, commit hash, OS/Python/Node versions, dependency lock/version output, external tool versions, test logs, screenshots, adapter smoke outputs, security scan, evidence ledger, and rollback notes.

Dual-edition bundles must include windows_worker, ubuntu_vps, and cross_edition evidence.

UI bundles must include dashboard screenshot, each tab screenshot, docked/undocked/fullscreen screenshots where supported, and visual comparison result.
