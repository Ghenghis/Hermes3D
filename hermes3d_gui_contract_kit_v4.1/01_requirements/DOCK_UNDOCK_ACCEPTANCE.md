# Dock / Undock / Fullscreen Acceptance Requirements

Hermes3D must support external tools in docked, undocked, and fullscreen/external states when feasible.

Acceptance gates: docked panel opens, undocked window resizes, fullscreen/external launch works or reports unsupported, closing external window does not kill backend, screenshots captured.

Tools requiring gate: Blender, Fluidd, Mainsail, OctoPrint, Printrun, FLSUN Slicer, PrusaSlicer, OrcaSlicer.
