# Dual Edition Requirements

Windows Desktop GPU Worker Edition owns GPU detection, Blender MCP, ComfyUI / 3D generation workers, slicers, Printrun USB control, Moonraker / OctoPrint LAN control, local proof signing, and dockable/undockable GUI.

Ubuntu VPS Control Server Edition owns auth, remote dashboard mirror, worker registry, remote job queue, tunnel health, proof archive, WebSocket relay, and secure dispatch to Windows GPU workers.

Both editions share UI routes, visual language, job states, proof bundle schema, adapter status, and agent activity model.
