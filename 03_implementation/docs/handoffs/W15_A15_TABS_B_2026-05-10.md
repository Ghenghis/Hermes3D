## Files touched

- `03_implementation/ui/src/tabs/Printers.tsx` — added W6-9 safety-state badge
  (locked / read_only / write_enabled / policy_unknown) shown alongside
  connection status, with aria-label + title for screen readers and
  `data-safety-state` for visual oracle.
- `03_implementation/ui/src/tabs/Observe.tsx` — added a `role="status"`
  `aria-live="polite"` `aria-atomic="true"` SR-only live region that
  announces refresh state, online/total count, and backend errors so
  operators using screen readers get camera state changes without
  interrupting their flow (WCAG 2.1 SC 4.1.3).
- `03_implementation/ui/src/tabs/Agents.tsx` — added a `HermesAgentVersionRibbon`
  Panel at the top of the tab that reuses the W6-5 `HermesAgentBanner`
  component and surfaces installed tag, latest release tag, and outdated
  status from `useAgentUpdateStatus()` (`/api/agents/update/status`). Honest
  when the backend is offline (renders "Hermes Agent offline" amber, never
  fakes a version).
- `03_implementation/ui/src/tabs/Learning.tsx` — added a static
  `LEARNING RESOURCES` section with four pinned upstream links
  (NousResearch/hermes-agent, Ghenghis/Hermes3D, Ghenghis/HermesProof,
  Google A2A spec). These are real reference URLs the operator can verify
  offline, not generated from any backend.
